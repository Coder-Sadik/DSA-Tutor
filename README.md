# Golpe Golpe DSA (গল্পে গল্পে ডেটা স্ট্রাকচার ও অ্যালগরিদম)

An interactive, bilingual (Bengali + English) ebook website built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and MDX.

## Project Directory
The complete web application is located in [`golpe-golpe-dsa/`](./golpe-golpe-dsa).

### Quick Start
```bash
cd golpe-golpe-dsa
npm install
npm run dev
```

### Run Tests
```bash
cd golpe-golpe-dsa
npm test
```

### Production Build
```bash
cd golpe-golpe-dsa
npm run build
```
